# Support for I Need My Credits

First try the [connection and update guide](docs/TROUBLESHOOTING.md).

- **Something broke:** [Report a problem](https://github.com/srluismiguelj/i-need-my-credits/issues/new?template=bug.yml).
- **An idea or provider request:** [Suggest an improvement](https://github.com/srluismiguelj/i-need-my-credits/issues/new?template=feature.yml), or use **Suggest a feature** in the app.
- **Private support:** ineedmycredits.support@gmail.com.
- **Security concern:** follow [Security](SECURITY.md) and report privately.

Include the INMC version shown in the footer, macOS version, Apple silicon or Intel, the provider affected, what happened and what you expected. Public GitHub issues can be read by anyone. Never include passwords, API keys, authorization links, cookies, conversations or private account data.

INMC is an independent personal experiment. No paid support or response-time guarantee is implied. Provider subscriptions and account access are managed by OpenAI or Anthropic.
