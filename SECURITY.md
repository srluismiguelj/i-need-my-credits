# Security

## Report a vulnerability privately

Email **ineedmycredits.support@gmail.com** with the subject **INMC security report**. Describe the affected version, impact and minimal reproducible steps without including real credentials or other users' information. Please do not put exploitable details or private data in a public issue.

## Official distribution

Download only from https://ineedmycredits.com/descargar or the releases of https://github.com/srluismiguelj/i-need-my-credits. Compare the DMG SHA-256 with the checksum included in that release. Official direct-download installers are Developer ID signed and notarized by Apple. Notarization is a distribution security check, not an endorsement.

Use the latest stable release for fixes. This personal project does not promise support for every historical version or a fixed response time. The application source is maintained privately; this public repository is the release and documentation hub.

INMC does not ask you to share passwords, API keys, cookies or conversations in support requests. See the [privacy policy](https://ineedmycredits.com/privacidad) for current data handling.
