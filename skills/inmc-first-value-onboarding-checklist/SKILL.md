# Design an onboarding checklist for first value

Use this workflow when asked for this output. Request the relevant inputs below if they are missing. Use the sample only if the user wants to practice. Respond in the user’s language.

## Inputs

Bring the first user goal, what is genuinely required, optional steps and observed setup friction. Aggregate counts are optional.

## Method

Return a checklist of at most five steps that ends in a user-visible result. For each step give action and success evidence. Add one common error with a genuine recovery path and specify the eligible population for an activation measure. Defer optional steps and mark unverified permissions. Do not change onboarding, send reminders or request access.

## Practice input

Fictional export app: first value is opening a valid exported report. User needs a file with two columns. Choosing a theme and inviting a teammate are optional. Invalid files currently show a generic error.

## Verify

- Check every required step against the actual product.
- Keep opt-in, permission and product activation concepts distinct.

## Expected output

- Checklist: get the sample CSV, upload it, confirm the preview, export and open the report.
- Recovery: show the two required columns and a sample file when validation fails.
- Activation metric: eligible attempts that open the first valid export, when the product can verify it.
