# Check message match from campaign to landing page

Use this workflow when asked for this output. Request the relevant inputs below if they are missing. Use the sample only if the user wants to practice. Respond in the user’s language.

## Inputs

Provide one ad, search snippet or social post, its destination, audience and visible offer terms. No advertising account is required for the demo.

## Method

Create a four-row audit: source promise, first-screen evidence, CTA destination, verified conditions. Identify one mismatch, one corrective change and the downstream action to measure. Use only supplied or verified terms. Do not infer conversion lift, edit the live page or run ads.

## Practice input

Fictional ad: Download the free invoice checklist. Landing headline: Manage all your billing. Button: Request a demo. The free checklist exists below the fold as a PDF.

## Verify

- Promise, headline and action describe the same artifact.
- Confirm the PDF is actually free and available through the primary CTA.

## Expected output

- Show the free invoice checklist in the first screen with the actual PDF action. Move the demo invitation to secondary placement.
- Measure eligible landing sessions that reach the checklist download. Track qualified demo requests separately.
