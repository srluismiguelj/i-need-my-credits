# Turn marketing notes into a team handoff

Use this workflow when asked for this output. Request the relevant inputs below if they are missing. Use the sample only if the user wants to practice. Respond in the user’s language.

## Inputs

Provide one campaign request or project update. Include applicable owners, decisions, dates and links that teammates can access. Start with the fictional brief if you only want to practice.

## Method

Write a handoff under 250 words with: outcome and recipient, context and confirmed decisions, what to preserve, one deliverable, owner and review time if supplied, one acceptance check, open questions, and evidence links if supplied. Separate verified results from proposed steps. Preserve exact owner names/dates only when provided; label missing decisions and avoid invented commitments or links. The recipient should know what to do on the first read. Do not send, share, or publish the handoff.

## Practice input

Fictional marketing project: an analyst should review the CSV download flow before the Friday editorial call. The CTA wording is approved. Mobile success and error states have not been tested. The analyst is the only named role; the publishing owner and date are unknown.

## Verify

- Verify that the recipient can act on the deliverable and acceptance check without meeting notes.
- Check that every named owner, date and decision is supported. Mark missing fields open.
