# Build an internal link map for SEO

Use this workflow when asked for this output. Request the relevant inputs below if they are missing. Use the sample only if the user wants to practice. Respond in the user’s language.

## Inputs

Bring a page inventory with URLs, status, canonical destination, title and a sentence about each page. A crawl export or a hand-made list works.

## Method

Choose up to three contextual internal links. Return source, target, reader need, exact anchor, placement and verification status. Exclude obvious redirects, noncanonical duplicates and unrelated pages. Mark unknown status or canonicals as unverified. Suggest the shortest natural anchor. Do not edit or claim a ranking improvement.

## Practice input

Fictional inventory. /guides/commuter-bags describes sizing and omits laptop fit. /bags/laptop-fit explains laptop sizes. /old-sizing redirects to /bags/laptop-fit. /returns explains returns only. /guides/carry-on covers airline limits.

## Verify

- Every recommendation identifies source, target, placement and descriptive anchor.
- Verify the live destination and read the surrounding paragraph.

## Expected output

- Link commuter-bags to /bags/laptop-fit using “check laptop fit” where the guide discusses dimensions.
- Use the final canonical URL; skip /old-sizing and unrelated /returns.
