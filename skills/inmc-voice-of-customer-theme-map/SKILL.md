# Turn customer feedback into a theme map

Use this workflow when asked for this output. Request the relevant inputs below if they are missing. Use the sample only if the user wants to practice. Respond in the user’s language.

## Inputs

Bring a small set of public excerpts you can quote or anonymized snippets you can use. Give each an ID and its collection context.

## Method

Map up to five themes. For each return customer task, observed friction, unique evidence IDs when known, unresolved assumption and validation step. Separate duplicates, requests and observed failures. Label any severity rating as judgment. Do not collect new data, quote private material without permission or generalize the sample to the market.

## Practice input

Fictional notes: A says exports are buried. B says the export shortcut is hard to find. C says export fails above 100 rows. D repeats B from the same contributor. E asks for more chart colors.

## Verify

- Counts use independent notes and supplied context only.
- Keep a minority or critical severity signal visible even if it has one note.

## Expected output

- Export discoverability has two independent notes (A, B), plus one duplicate (D).
- Export reliability is separate (C) and needs a reproduction. Chart colors are a separate request (E).
