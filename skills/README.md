## Use a skill in a project

1. Open a skill below and read the instructions. Use the linked guide if you need its sample files.
2. Save the file as SKILL.md under the same skill folder name inside .agents/skills/ for a Codex project or .claude/skills/ for a Claude Code project.
3. Open that project in your AI tool and ask for the skill by name. Start with the worked example or provide only inputs you can share.

See the [Codex skill guide](https://learn.chatgpt.com/docs/build-skills) and the [Claude Code skill guide](https://code.claude.com/docs/en/skills) for setup and compatible versions.

On Mac, [I Need My Credits](https://ineedmycredits.com/descargar?utm_source=github&utm_medium=referral&utm_campaign=inmc_skills) shows remaining plan capacity and reset times for Codex and compatible Claude Code accounts. The skills also work without the monitor. Your AI plan and account limits still apply.
