# Repurpose a published guide for two social channels

Use this workflow when asked for this output. Request the relevant inputs below if they are missing. Use the sample only if the user wants to practice. Respond in the user’s language.

## Inputs

Use one published piece you can reuse. Provide exact facts, eligible examples, the approved destination and the intended channels.

## Method

Return two channel-ready drafts, each with a distinct hook, one action the reader can try, and one CTA. Keep numbers and claims traceable to the guide, label fictional examples, and mark missing link access. For Instagram also suggest a two-frame outline. Do not post, message, or schedule.

## Practice input

Fictional guide: an audit removes one duplicated order row. Raw export 101 rows. Clean export 100 orders. LinkedIn can link directly. Instagram directs to a verified profile link to the same guide.

## Verify

- Every number and constraint matches the source.
- Each draft has one action and a destination actually available on that channel.

## Expected output

- LinkedIn starts with the consequence for the report and includes one direct CTA.
- Instagram opens on a visual comparison of 101 rows and 100 orders and labels the example as fictional.
- Each variant gives one practical check a reader can apply.
